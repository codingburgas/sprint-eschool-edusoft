<h2 id="about-the-project">About The Project</h2>

<p align="justify">
    <p>This is a science knowledge test with three categories: Biology, Chemistry, and Physics. Each test has 20 questions with three answer choices: A, B, or C. The user selects a category and answers the questions one by one. After each question, the program shows if the answer is correct or wrong. At the end, the user gets a final score based on correct answers. This test helps to check and improve knowledge in science.</p>
